# UI fonts

- `Baloo2.ttf`: [Baloo 2](https://github.com/google/fonts/tree/main/ofl/baloo2), used for headings and buttons. License: `OFL-Baloo2.txt`.
- `NunitoSans.ttf`: [Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans), used for controls and body text. License: `OFL-NunitoSans.txt`.

Both files were downloaded from the Google Fonts repository. The app registers them with Qt on startup, so users do not need to install fonts on Windows.
